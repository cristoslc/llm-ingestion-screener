# Tech debt

Pre-existing LSP errors, lint violations, type errors, and other debt too complex to fix inline, recorded so it is tracked rather than silently tolerated.

## Convention

One file per item, or one index file with entries. Each entry names the file and symbol, the diagnostic, why it is out of scope for the change that found it, and a suggested fix.
