# Purpose

Build a pre-read safety screener for LLM ingestion: a small, local-first component that inspects material before it enters an agent's context — fetched web pages, search results, documents, third-party skills, tool output — and returns a typed verdict on whether the material is safe to read or carries prompt injection or other hazards. The screener is built around decision ("System One") models such as Clef, Jev, and Kev, which turn a state plus a schema of typed questions into scored answers, combined with deterministic rules. It exists because a research agent on this workstation was attacked by prompt injection embedded in results returned from prominent sources. The outcome is a reusable screening stage the operator's agent harnesses can call on every inbound document.
